Add the journal subject wrapper: `journalSubject(schema, options)` declares how a subject is journaled (`retention`, `retainPayload`, `schemaVersion`, `readOlder` for recorded events; `suggestedFor` for events and requests). It wraps a bare schema or exactly one routing wrapper and is always the outer layer; a journal inside a journal, two stacked routing wrappers and recording options on a request are rejected at the type level. `SubjectSchema` now includes `JournalSubjectSchema`, and `journalSubject` is also exported from `@makaio/bus-core`. One traversal, `inspectSubjectSchema`, reads the marks of the outer layer and, below a journal layer only, of the one layer it wraps; the wrapper guards, `unwrapSchema`, the namespace registry (which keeps the journal declaration of a registered subject) and the protocol manifest export use it. `ProtocolNamespaceCatalogEntry.schemas` accepts any `SubjectSchema`. `journalSubject()` returns a frozen wrapper holding a deep-frozen copy of its options, `inspectSubjectSchema` reads every journal layer into a frozen copy and returns its own marks object, and `getRegisteredSubject()` returns a copy of the registration record. Generated subject pages now unwrap every routing wrapper, so collector-only and default-transports subjects list their payload fields.

Breaking: the wrapper guards (`isLocalSchema`, `isChannelSchema`, `isCollectorOnlySchema`, `isHostLocalRequestSchema`, `isDefaultTransportsSchema`) also accept a journal layer over their wrapper and narrow to that union, so code that reads `schema` or a brand field directly after a guard must handle the journal layer (or use `unwrapSchema` or `inspectSubjectSchema`).

`ExternalObjectRefSchema` reads the `parent` chain once into null-prototype copies (own enumerable data properties, primitive values except `parent`, no functions; accessors, foreign prototypes, functions and proxies whose reflection fails are rejected with an ordinary issue) and validates only those copies: under the default parse options, property getters of the reference are never invoked and the reference itself runs caller code only as Proxy traps during that one caught read (with `reportInput: true`, zod attaches and serializes the input itself; a setter installed on `Object.prototype` still runs when zod assigns the fields of its result object, as for every object schema). Breaking: references that are not plain objects (class instances, objects created in another realm) or that carry accessors, functions or object-valued fields other than `parent`, which the schema accepted before, are now rejected.
