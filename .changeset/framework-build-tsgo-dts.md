'@makaio/framework': patch
---

Add a `MAKAIO_FRAMEWORK_BUILD_TSGO_DTS` switch that emits the framework distribution's type declarations through `tsgo` instead of the declaration bundler's in-process TypeScript compiler. Declaration emit dominates cold build time — one serial TypeScript program across every stage entry — and `tsgo` natively emits declarations with an identical exported API surface before the bundler links them (the emitted files are not byte-identical: `tsgo` drops TSDoc attached to private class members, which never reaches the public API, and links some entries into structurally larger output). The switch is opt-in while the backend is experimental; unset, the build behaves exactly as before, and it is ignored under `MAKAIO_FRAMEWORK_BUILD_SKIP_DTS`, which emits no declarations at all. The dist build stamp records which backend emitted the declarations, so a `tsgo`-stamped dist never satisfies a default-backend caller's freshness check. A new workspace-root `tsconfig.build.json` provides the declaration-emit project: it extends the type-checking project so the `paths` map stays single-sourced, and narrows the emitted file set to the sources a distribution entry can reach.

The dist verifier gains backend-independent structural checks that hold regardless of the switch. Exports-map declaration targets that declare no API surface are rejected — a zero-byte `.d.mts`, one holding only comments, and one holding only a bare `export {};` marker are equally surface-free, and all resolve as a module with no exports, silently presenting the subpath as untyped instead of failing to resolve. Every shipped declaration file is scanned for surviving workspace import specifiers, which no consumer could resolve, and self-imports of the published package are validated against the exports map — the bundler rewrites cross-entry type imports to umbrella subpaths whether or not those are public. That last check surfaced a shipping defect this release also fixes: the `adapter-subsystem` declarations reference `@makaio/framework/services/settings`, whose entry was built but never exported; the subpath is now part of the public exports map. The declaration checks are skipped only for a runtime-only distribution, which ships no declarations to inspect.
